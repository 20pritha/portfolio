# Pritha Mishra Portfolio

Clean, minimal Next.js 14 App Router portfolio for AI Engineer Pritha Mishra.

## Setup

```bash
cd /Users/prith/Downloads/portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Uses Tailwind CSS, Framer Motion, and Recharts.
- Contact form is wired for EmailJS via env vars.
- Deploy-ready for Vercel.
